## What landed in U8G2GL (#11)

- **`library.json`.** PlatformIO consumers pin the runtime by git commit.
- **The version is checked at configure time.** CMake refuses if `library.json` disagrees with
  `u8g2gl_version.h`.
- **Every submodule is `update = none`.** PlatformIO clones git dependencies `--recursive`;
  without this a consumer fetched about 200 MB and two private repositories. Contributors now
  use `--checkout`.
- **No `library.properties`.** The Arduino 1.5 format includes only `src/`, so the Arduino half
  of §16 needs a header-layout decision first. **Open for you.**

## Runtime and CLI findings: reported, not fixed (a PR is needed)

1. **The runtime never calls `setFontPosTop()`, but every text widget assumes it.** A plain
   `begin()` + `ui_handler()` user gets **15 lit pixels instead of 1392**. **High: the first thing
   a new user hits.** Foundation is unaffected only because its legacy module sets it.
2. **The state saver restores a null font,** which segfaults on the first frame
   (`u8g2gl_state_saver.h:80-83`).
3. **The state saver does not restore the font mode,** though it is readable through
   `font_decode.is_transparent`.
4. **A screen file not named `screen_*.xml` is silently ignored:** exit 0, "0 screens".
5. **The generated config's PlatformIO advice fails.** A project-wide `-include` breaks on the
   first unrelated library. A build middleware scoped to the runtime's sources works, and cuts
   the binding pool from 6144 B to 96 B. Recommend that form in the header's comment, or make the
   header path a macro.
6. **`library.json` `frameworks: "arduino"` keeps the runtime out of native builds.** Foundation
   works around it with a unity file.
